# Banking Account Management System

## Overview
This project implements a simple banking/account management system in Python. It includes:

1. **Task 1:** Customer and profile creation.
2. **Task 2:** Account operations (deposit, withdraw, transfer) and testing.
3. **Task 3:** Advanced exercises and workflow exploration.

All data is stored in CSV files: `user_records.csv` and `account_transactions.csv`.

---

## Features

### Task 1 - Customer Management
- Create new users with automatic **UserID generation**.
- View and update user profiles.
- Supports creation via list, keyboard input, or existing UserID.

### Task 2 - Account Management
- Create transaction accounts linked to UserID.
- Track balance, deposits, withdrawals, and fund transfers.
- Includes testing scripts for account operations.

### Task 3 - Exercises
- Starter code and notebooks for additional exercises.
- Explore workflows, modify transactions, and extend functionality.
